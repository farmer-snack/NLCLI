删除构建版本后出现的屏幕水印 - 实现说明
================================================

问题描述
--------
删除构建版本（即运行开发构建 / 非正式发布版本）后，ClassIsland 窗口底部会显示
水印文字“开发中画面，不代表最终品质。”以及版本号。该水印由开发构建装饰层
（DevelopmentBuildAdorner）在 MyWindow 加载装饰层时添加。

实现方法
--------
水印的添加逻辑位于 ClassIsland.Core\Controls\MyWindow.cs 的装饰层初始化方法中。
原逻辑在以下任一条件满足时都会添加 DevelopmentBuildAdorner：
  - AppBase.Current.IsDevelopmentBuild 为 true（开发构建/删除构建版本后出现）
  - MyWindow.ShowOssWatermark 为 true（通过 --showOssWatermark 命令行参数开启的开源地址水印）

由于开源地址水印属于独立的许可/合规要求（由命令行参数 --showOssWatermark /
-ossw 控制），不应被删除；因此仅移除了“开发构建”触发条件，保留开源水印逻辑。

修改位置：ClassIsland.Core\Controls\MyWindow.cs
原代码：
    if ((AppBase.Current.IsDevelopmentBuild || ShowOssWatermark))
    {
        var adorner = new DevelopmentBuildAdorner(AppBase.Current.IsDevelopmentBuild, ShowOssWatermark);
        layer?.Children.Add(adorner);
        AdornerLayer.SetAdornedElement(adorner, element);
    }

修改后：
    if (ShowOssWatermark)
    {
        var adorner = new DevelopmentBuildAdorner(AppBase.Current.IsDevelopmentBuild, ShowOssWatermark);
        layer?.Children.Add(adorner);
        AdornerLayer.SetAdornedElement(adorner, element);
    }

效果
----
- 开发构建（删除构建版本后）不再显示“开发中画面，不代表最终品质。”及版本号水印。
- 通过命令行参数 --showOssWatermark 显式开启的开源地址水印（https://www.classisland.tech）
  仍保持原有行为，不受影响。
- DevelopmentBuildAdorner 控件类及其 axaml 模板无需改动，仅在开发构建条件下不会
  再被实例化/添加到装饰层。

验证
----
使用 `dotnet build ClassIsland.Core\ClassIsland.Core.csproj -c Debug` 编译通过，
0 个错误（仅有 XML 注释和过时 API 的既有警告，与本次改动无关）。

相关文件
--------
- ClassIsland.Core\Controls\MyWindow.cs            （修改：移除开发构建水印触发条件）
- ClassIsland.Core\Controls\DevelopmentBuildAdorner.cs   （未改动，仅保留供 OSS 水印使用）
- ClassIsland.Core\Controls\DevelopmentBuildAdorner.axaml （未改动，模板中的开发构建文字块仍由 IsDevelopmentBuild 绑定控制可见性）
- ClassIsland\Program.cs / ClassIsland\Models\ApplicationCommand.cs / ClassIsland\App.axaml.cs
  （未改动，--showOssWatermark 相关逻辑保持不变）
