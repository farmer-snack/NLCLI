一、项目总览
------------

ClassIsland 是一款面向班级多媒体屏幕的跨平台课表信息显示工具。应用以 Avalonia UI 为界面框架，
核心功能包括：显示当前课程与课表、上下课提醒、组件化主界面、课表/时间表/科目编辑、自动化、
天气、主题、插件、集控管理、自动更新等。

技术栈要点：
- .NET 10（Main 项目）；ClassIsland.Shared / Shared.IPC 在 Windows 下同时目标 net10.0 与 net472。
- Avalonia 12.1.4 + FluentAvalonia 3.0.0，MVVM 使用 CommunityToolkit.Mvvm 与 DynamicData/ReactiveUI。
- 依赖注入使用 Microsoft.Extensions.Hosting / DependencyInjection。
- 插件系统通过 PluginSdk、PluginLoadContext、manifest.yml 和 IPC 扩展。
- 桌面端按 Windows / Linux / macOS 拆分平台实现；Android 复用同一套 Avalonia 页面代码。
- 发布与打包使用 NUKE（build/ 目录），支持 folder、deb、pkg、MSIX、APK 等产物。

二、整体架构与启动流程
----------------------

1. 桌面入口
   ClassIsland.Desktop/Program.cs
     -> 初始化平台服务（PlatformServices）
     -> 调用 ClassIsland.Program.AppEntry(args) 解析命令行并创建 App 工厂
     -> 用 Avalonia AppBuilder 配置 App、字体、Skia、Win32 渲染模式
     -> StartWithClassicDesktopLifetime 启动桌面生命周期

2. 应用主体
   ClassIsland/Program.cs
     -> 注册 JSON 转换器、解析命令行、单实例 Mutex、Sentry、MoonSharp
     -> 返回 () => new App()
   ClassIsland/App.axaml.cs
     -> App : AppBase，负责应用生命周期、主窗口、崩溃处理、更新、插件加载等
   ClassIsland/App.Services.xaml.cs
     -> ConfigureServices：注册所有服务、ViewModel、设置页、组件、触发器、行动、通知提供方等

3. 核心库
   ClassIsland.Core
     -> 插件与扩展点抽象（Abstractions/Attributes）
     -> 通用控件、转换器、主题、行为、助手
     -> 设置页、组件、通知、规则、教程、天气、插件市场等模型
   ClassIsland.Shared
     -> 课表档案（Profile/ClassPlan/TimeLayout/Subject）、自动化 ActionSet、通知、集控模型
   ClassIsland.Shared.IPC
     -> 基于 dotnetCampus.Ipc 的跨进程接口与客户端
   ClassIsland.Platforms.Abstractions
     -> 平台服务接口与 Stub 默认实现

4. 平台实现
   platforms/ClassIsland.Platforms.Windows
   platforms/ClassIsland.Platforms.Linux
   platforms/ClassIsland.Platforms.MacOs
   ClassIsland.Android
     -> 分别实现窗口、桌面、通知、定位、设备信息、系统事件等平台能力

五、ClassIsland.Desktop（桌面宿主）
----------------------------------

ClassIsland.Desktop 是可执行入口项目，负责选择桌面平台实现并以 Avalonia 桌面生命周期启动主程序。
它本身几乎没有业务代码，主要做“平台装配”。

ClassIsland.Desktop/Program.cs
  桌面进程入口。根据编译常量激活 Windows/Linux/macOS 平台服务；用 AppBuilder 配置 App、
  字体回退、Skia GPU 缓存、Win32 渲染模式、资源覆盖加载器和日志；最后进入桌面生命周期。
  同时提供 BuildAvaloniaApp 供设计器使用。

ClassIsland.Desktop/Services/Platform/DesktopAppLifetimeService.cs
  IAppLifetimeService 的桌面实现：调用 Avalonia 桌面生命周期退出应用，或用当前进程路径重新启动。

ClassIsland.Desktop/Services/Platform/LauncherService.cs
  ILauncherService 的桌面实现：用系统默认程序打开文件/文件夹/URL；支持 Avalonia 文件选择器的书签路径。

ClassIsland.Desktop/ClassIsland.Desktop.csproj
  桌面可执行项目文件。目标 net10.0（按平台追加 -windows/-macos），引用主项目、平台抽象和对应平台实现；
  配置 Windows 应用清单/图标、macOS Bundle 资源、Linux DEB 包元数据、平台常量与发布属性。

ClassIsland.Desktop/app.manifest
  Windows 应用清单：DPI 感知、UAC 权限、兼容性设置等。

ClassIsland.Desktop/Info.plist
  macOS 应用包 Info.plist：Bundle 标识、版本、最低系统版本、URL Scheme 等。

ClassIsland.Desktop/Properties/launchSettings.json
  本地调试启动配置（命令行参数、环境变量）。

ClassIsland.Desktop/Assets/AppIcon.icon/icon.json
  macOS 26+ Liquid Glass 应用图标描述。

ClassIsland.Desktop/Assets/AppLogo.xcassets/…/Contents.json
  macOS 各尺寸应用图标资源目录的元数据。

ClassIsland.Desktop/Assets/AppIcon.icns、AppLogo.ico、AppLogo.svg、AppLogo@32w.png
  macOS/Windows/Linux 打包所需的各格式应用图标。

ClassIsland.Desktop/Assets/AppIcon.icon/**、AppLogo.xcassets/**

  - Client/*.proto：客户端请求（握手、注册、配置上传、审计、命令投递）；
  - Command/*.proto：服务器命令（获取配置、心跳、发送通知）；
  - Enum/*.proto：审计事件、命令类型、配置类型、列表更新操作、返回码；

十五、ClassIsland.Core（核心库）

ClassIsland.Core 是应用与插件的公共基础库，提供：
- 插件扩展点基类与元数据特性；

十六、ClassIsland（应用主体）根文件
------------------------------------

ClassIsland 是应用主体项目，包含 Avalonia 界面、业务服务、视图/ViewModel、组件、通知、
自动化、日志、更新、插件宿主等全部实现。桌面和 Android 宿主都引用它。

ClassIsland/ClassIsland.csproj
  应用主体项目文件。OutputType=Library，目标 net10.0；引用 Core、Shared、Shared.IPC、
  平台抽象、所有平台实现（按条件）、Avalonia、FluentAvalonia、Sentry、SoundFlow、
  EdgeTtsSharp、OpenCvSharp 插件依赖等；配置资源打包、MSIX、插件输出和 Android 复用。

ClassIsland/App.axaml
  应用级 XAML：合并主题资源字典、定义全局样式、数据模板、转换器与字体资源。

ClassIsland/App.axaml.cs
  应用生命周期核心：初始化 DI 容器、加载设置与档案、启动/停止服务、创建主窗口、
  处理全局异常、更新检查、插件加载与退出流程。

ClassIsland/App.Services.xaml.cs
  服务注册入口：把服务、ViewModel、设置页、组件、行动、触发器、通知提供方、
  规则、教程、语音、主题、IPC 等注册到 Microsoft.Extensions.DependencyInjection。

ClassIsland/MainWindow.axaml
  主窗口界面：无边框窗口、课程主界面、组件容器、编辑模式、抽屉、Toast、遮罩层等。

ClassIsland/MainWindow.axaml.cs
  主窗口逻辑：窗口尺寸/位置/层级、主界面组件加载、编辑模式、全屏、点击穿透、
  显示隐藏动画、系统事件响应。

ClassIsland/MainWindow.VisibilityAnimation.cs
  主窗口显示/隐藏动画的分部实现（淡入淡出、位移）。

ClassIsland/Program.cs
  主程序入口：解析命令行、注册 JSON 转换器、单实例 Mutex、Sentry 初始化、
  MoonSharp 脚本环境初始化，返回 App 工厂给 Avalonia 生命周期。

ClassIsland/PluginLoadContext.cs
  插件 AssemblyLoadContext：按插件目录解析依赖、隔离插件程序集；
  macOS/Android 使用 MonoPluginAssemblyResolver 兼容 Mono 加载方式。

ClassIsland/OverlayAssetLoader.cs
  Avalonia 资源加载器包装：允许用本地目录/程序集资源覆盖内置 avares 资源，
  用于主题、图标和调试时的资源热替换；含 AssetOverride 记录。

ClassIsland/RegistryNotifier.cs
  Windows 注册表变更监听封装（RegNotifyChangeKeyValue），用于监听系统主题色等变化。

ClassIsland/AccentColorPicker.cs
  系统强调色选择器占位/预留实现（当前为空类）。

ClassIsland/ColorOctTreeNode.cs
  八叉树颜色量化节点（用于从壁纸提取主题色）；当前整体位于 #if false 中，为历史实现。

ClassIsland/GlobalUsing.cs
  全局 using 声明，统一常用命名空间。

ClassIsland/AssemblyInfo.cs
  应用主体程序集元数据。
